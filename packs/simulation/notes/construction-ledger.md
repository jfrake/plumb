This is a simulation paper. Enter each parameter the paper varies across simulated conditions as role `treatment`, each simulated outcome metric as `DV`, and each parameter held fixed as `control`. Set `source_data` to `simulated: <model family>`; that is correct, not a missing source. Set `level_of_measurement` to `individual` when the unit is an agent, `firm` when it is an organization, and `other` otherwise, with the model's own term in `construction_caveats`. Set `time_variation` to `time-varying` for outcomes tracked over periods and `time-invariant` for parameters fixed within a run. Enter variables the paper measures from data as usual. Do not set `no_entries_reason` because the paper has no data: the simulation's parameters and outcomes are its entries.
