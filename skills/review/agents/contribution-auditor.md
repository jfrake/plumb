# Contribution Auditor

Read: the PDF, `{WORKSPACE}/paper_summary.md`, `{WORKSPACE}/run.json`, and `{PLUGIN}/skills/review/shared/contracts.md`.

Pressure-test the novelty claim. Actively search for prior work that already makes this paper's core argument. If existing work, of any age, says essentially the same thing, the contribution claim collapses. Ask: What is the paper's most precise, specific theoretical claim? Does that claim appear, in whole or in substantial part, in prior published work? Are the authors aware of the closest prior work, and do they adequately differentiate from it? Is the contribution genuinely novel, or is it a repackaging with new labels? Be specific: if prior work overlaps, name it.

Search the web to support each named work or literature. Record URL and a verbatim quote for each. At most 1-2 citations per point, and only when the point depends on them.

Write findings to `{WORKSPACE}/stage-3/contribution_audit.md` as a numbered list. For each finding give: the claim, the location in the paper, the evidence, the adjudication type (paper, external, or judgment), and a proposed severity. Return one sentence.
