# Rater instructions

Source: the instruction screen of `rating_page.html`, as the rater saw it.

Each screen shows one point about one of four papers. The points come from several sources and are written in the same plain style. Rate each point as you would if a colleague had raised it about your paper.

**Is the point correct?** Valid: the problem is real as stated. Doubtful: it may be real, but it overstates or misreads the paper. Wrong: the paper already handles it, or the point is mistaken.

**How much does it matter?** Undermines the main claim: if true, the main result does not hold as stated. Weakens a claim: it narrows or qualifies a claim. Minor: it improves the paper without changing a claim. Rate importance as if the point were correct.

**What kind of point is it?** Factual: the paper or an outside source can settle it, such as a number that does not match its table or a misdescribed citation. Substantive judgment: a call about the design, the argument, or the contribution that affects whether the claims hold. Preference: a matter of framing, emphasis, or style that does not change whether the claims hold.

Answers save as you go. You can stop and come back, and go back to change any answer. Keys 1 2 3 set correctness, Q W E set importance, A S D set the kind, Enter moves on.

The rater sees the paper label, the paper's title, and the point. The source, the class, and any match are hidden. Items appear one at a time, in a fixed random order within each paper, with the papers in random order.
