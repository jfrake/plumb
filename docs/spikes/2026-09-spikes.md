## Spike B: Tables (2026-09-25)
- Compared three ways to get numbers out of table images/pages on the same test set of tables.
- pdfplumber-only extraction: 24.1% numeric-cell error rate, and it silently lost one table entirely (no error, no output for that table).
- Docling: 77.5% numeric-cell error rate (about 36% if coefficient/SE pairs that Docling merged into one cell are forgiven).
- A model reading the rendered page images: 0.37% error rate (3 of 819 cells).
- Decision: tables are read by having the model transcribe each table from page images twice, independently, then a script (`compare_transcriptions.py`) diffs the two transcriptions cell by cell. Disagreements go to the number-flags check-in rather than being silently resolved. Docling is dropped; it is not used anywhere in the pipeline.
